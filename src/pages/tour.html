Values and loops

const never changes, var does. #name and #(expr) go inside strings. //~ is a doc comment; an ordinary comment is ///, because plain // is a lexer error with a hint.

{{code:values}}

Access modes

Arguments are read-only unless you say otherwise. inout lets the function change the caller's value and sink hands it over. Both are repeated at the call, so the call site shows what happens. Memory safety comes from these rules and value semantics, not from a borrow checker.

{{code:modes}}

Errors and absence

There are no exceptions and no null. T ! e is a result, T? is an option, none is the empty one, and ? returns early with the error. ?? supplies a default.

Closures and builders

x ~> x * 2 is a closure, and ~> it * 3 uses the implicit it. A list builder maps and filters in one expression.

Patterns

One switch matches enums, literals, guards and lists. Leave a case out and the checker says so.

Overflow

Arithmetic that overflows stops the program. If you want wrapping, say so with +% and *%. The native backend keeps this behaviour, which is why the benchmarks compare against C that is allowed to ignore it.
