Install

There are no prebuilt downloads yet, so you build the tool from source. It has no dependencies besides Rust, and a release build takes about half a minute.

1. Get Rust

Install the stable toolchain from rustup.rs. On Windows that is rustup-init.exe.

2. Build Pelago

In PowerShell (the same commands work in any shell):

git clone https://github.com/pelagolang/pelago
cd pelago
cargo build --release

The tool is target\release\pelago.exe on Windows and target/release/pelago elsewhere. To put it on your PATH in one step:

cargo install --path compiler

Cargo's bin folder (%USERPROFILE%\.cargo\bin on Windows) must be on your PATH; rustup normally adds it. Restart the terminal afterwards.

3. Run something

pelago run examples\hello.pel
pelago build -o hello examples\hello.pel
.\hello

run checks the program and runs it in the interpreter (add --native to build and run machine code). build writes a native executable, with no linker and no libc involved. Without installing, replace pelago with cargo run --release --.

Commands

pelago check <path>
Parse, resolve names and check types.
pelago run <path>
Run main in the interpreter. --opt optimises first, --stats counts, --native uses machine code.
pelago build -o out <path>
Native executable. --target=windows or Linux, --arch=aarch64, --no-opt, --leak-check.
pelago fmt <path>
Format .pel files in place; --check only reports.
pelago lsp
The language server, used by the editor extensions.
pelago highlight <file>
Colour a file as ANSI, HTML or plain text.

The full list is in the README.

Targets

Native builds target x86-64 Linux (ELF) and Windows (PE), and AArch64 on Linux and Windows. Cross-compiling needs no extra tools.
