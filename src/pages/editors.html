Editors

Highlighting for .pel files in VS Code and Zed, and errors as you type from the language server in both. Extensions never change your theme: Pelago colours apply to .pel files only.

Language server

Both extensions start pelago lsp for diagnostics, hover, go to definition, references, completion and outline. Install the pelago tool first (see Install) and check that pelago --help works in a new terminal. On Windows, restart the editor after changing PATH.

VS Code

Install Pelago on the Visual Studio Marketplace, or from a terminal:

code --install-extension pelagolang.pelago

You can also search for Pelago in the Extensions view. If pelago is not on PATH, set Pelago: Server Path to the full path of pelago.exe. To install a build by hand, download the .vsix from the latest release and use the ... menu in the Extensions view, then Install from VSIX.... Source and details: vscode-pelago.

Zed

Not in the Zed registry yet. Clone zed-pelago, open the command palette and run zed: install dev extension, then choose the folder. Zed builds the grammar itself, so you need Rust installed through rustup.

Neovim, Helix and others

tree-sitter-pelago is a Tree-sitter grammar with highlight queries, checked against the compiler's examples. Any editor that loads Tree-sitter grammars can use it.

Without an editor

pelago highlight --html file.pel produces the same colours as on this site, and --ansi prints them in a terminal.
