Pelago is a compiled systems language. Programs become native executables, memory is managed without a garbage collector, and the language has no runtime to ship alongside your code. Values behave like values, errors are ordinary results, and integer overflow stops the program instead of wrapping silently.

```pelago
fn main() {
    print("Hello, Pelago")
}
```

## What you can expect

- **One tool.** `pelago` checks, runs, builds, formats and serves editors.
- **Native output.** Executables for Linux and Windows on x86-64 and AArch64, with no linker and no C library involved.
- **Predictable behaviour.** No exceptions, no null, and exhaustive `switch`. Overflow, out-of-range indexes and similar faults stop the program with a message.
- **Small programs.** A hello-world executable is a few kilobytes.

The reference and standard library sections are being written. Every code sample on this site is compiled, and its output checked, before it is published.
