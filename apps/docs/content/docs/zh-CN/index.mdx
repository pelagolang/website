## 状态 [#status]

第 0 阶段编译器用 Rust 编写，没有任何依赖，已能处理整门语言。它检查类型和值语义，在 IR 解释器中运行程序，并为 Linux 和 Windows 生成原生可执行文件。这些文档是设计草稿：每篇都以已做出的决定收尾，有些页面比代码更旧，所以两者不一致时，以编译器和[决策表](/docs/project/roadmap)为准。

## 从这里开始 [#start-here]

- **初次接触 Pelago？** [语言导览](https://github.com/pelagolang/pelago/blob/main/examples/tour.pel)展示了每一种语法形式，[examples/programs](https://github.com/pelagolang/pelago/tree/main/examples/programs) 中是可以运行的程序。
- **想自己构建？** 克隆仓库并运行 `cargo build --release`；README 里有相关命令。
- **想参与贡献？** 请阅读[提交与 PR 标题](/docs/project/commits)和 [PR 场景](/docs/project/pr-scenarios)。
