Написано так, как мог бы выглядеть первый урок Python: по одной идее за раз. Синтаксис —
это набросок, на который можно реагировать, а не окончательное решение.

**Решено на данный момент:** `fn` для функций, `var` и `const`, имена типов в нижнем регистре,
целые числа размером от 8 до 64 бит, обобщения `<T>`, конец строки завершает инструкцию.

## 1. Переменная — это имя для значения [#1-a-variable-is-a-name-for-a-value]

```
var score = 10
const name = "Dennis"
```

- `var` создаёт переменную, которую можно изменить позже.
- `const` создаёт такую, которую изменить нельзя. Благодаря семантике значений «нельзя изменить» —
  это всерьёз: ничто, достижимое по этому имени, тоже не может измениться.
- Сначала идёт имя. Тип не пишется, потому что компилятор определяет его сам.

## 2. Изменение переменной [#2-changing-a-variable]

```
var score = 10
score = 15          // fine
score += 5          // score is now 20

const pi = 3.14
pi = 3.2            // error: pi is const
```

## 3. Типы [#3-types]

У каждого значения есть тип, а переменная сохраняет свой тип навсегда. Это главное
отличие от Python.

```
var score = 10
score = "ten"       // error: score is an int, "ten" is a string
```

| Тип | Хранит | Пример |
|---|---|---|
| `int` | целые числа | `42`, `-7` |
| `float` | десятичные числа | `3.14` |
| `bool` | истина или ложь | `true` |
| `char` | один символ | `'a'` |
| `string` | текст | `"hello"` |

Точные размеры на случай, когда важна память:

| Знаковый | Беззнаковый | Диапазон знакового |
|---|---|---|
| `int8` | `uint8` | -128 to 127 |
| `int16` | `uint16` | примерно от -32 тысяч до 32 тысяч |
| `int32` | `uint32` | примерно от -2,1 млрд до 2,1 млрд |
| `int64` | `uint64` | примерно от -9,2 квинтиллиона до 9,2 квинтиллиона |

а также `float32`, `float64` для десятичных чисел.

## 4. Явное указание типа [#4-writing-the-type-yourself]

Тип пишется после имени, как в TS. Он нужен, только когда компилятор не может
определить его сам или когда вы хотите быть явными.

```
var score: int = 10
const ratio: float = 0.5
var small: int8 = 100
var count: int            // error: a variable must be given a value
```

Переменной всегда нужно присваивать значение при создании. Нет неинициализированных
переменных и нет null, что устраняет целый класс ошибок.

## 5. Вывод и комментарии [#5-printing-and-comments]

```
print("Hello")
print(score)
/// this is a comment
```

## 6. Преобразование между типами (предложение, своё) [#6-converting-between-types-proposal-custom]

Преобразования всегда пишутся явно, никогда молча. Предложение: простое слово `to`.

```
const whole = 7
const decimal = whole to float      // 7.0
const text = whole to string        // "7"
```

Компилятор разрешает `to` только тогда, когда ничего не может быть потеряно. Преобразования,
которые могут потерять информацию или завершиться неудачей, потребуют другой, заметной записи.
Мы определим её, когда дойдём до ошибок.

## 7. Строки со значениями внутри (решено: наш собственный маркер `#`) [#7-strings-with-values-inside-decided-our-own--marker]

`#` и следующее за ним имя подставляют это значение в текст. Для всего, что больше
имени, используйте скобки.

```
print("Score: #score")              // Score: 10
print("Next: #(score + 1)")         // Next: 11
print("A literal hash: \#")         // A literal hash: #
```

Выражение проверяется при компиляции программы, поэтому ошибка обнаруживается до запуска.
Управление форматом (десятичные знаки, ширина), многострочные и «сырые» строки появятся позже
и этот маркер не изменят.

## Что уже наше собственное [#what-is-already-our-own]

Синтаксис — самое дешёвое место для отличий, поэтому список ниже в основном о том,
что язык *делает*. Всё здесь — осознанный выбор, а не копия.

- Язык, похожий на TS, но **без GC и без хранимых ссылок**, только семантика значений.
- **`inout` повторяется в месте вызова**, чтобы каждое изменение было видно там, где оно происходит.
- **`const`, действительно неизменяемый**, до самого дна.
- **Нет null.** Отсутствие — это тип (`option<T>`), а не сюрприз.
- **Преобразования записываются как `to`** и только когда ничего не теряется (предложение).
- **Строки с интерполяцией через `#`**, маркер, которого мы больше нигде не видели.
- **Один `switch`/`case`, который одновременно является сопоставлением с образцом.**
- **Экономия токенов как цель дизайна**, измеряемая настоящими токенизаторами.

## Решения из черновика 2 [#decisions-from-draft-2]

- **[B1]** Компилятор принимает любой стиль имён. Стандартная библиотека и форматтер выбирают один.
- **[B2]** `int` — всегда ровно 64 бита.
- **[B3]** Имена типов пишутся в нижнем регистре. (Открыто: и ваши собственные типы тоже?)
- **[B4]** Преобразования записываются как `x to float`.

- **[B5]** Интерполяция строк использует `#имя` и `#(выражение)`.
- **[B6]** Для ваших типов разрешены имена и в нижнем регистре, и с заглавной буквы. Компилятор
  принимает оба варианта, как и для имён переменных (B1). Форматтер и стандартная библиотека используют
  заглавную букву для определяемых вами типов, чтобы они выделялись. Тип и значение в одной области видимости не могут иметь одинаковое имя.

## Пока открыто [#still-open]

**[B7] Ключевое слово `let`.** Сейчас зарезервировано и не используется. Главный кандидат на будущее:
член тройки режимов доступа (`let` / `inout` / `sink`), доступный только для чтения, возможно необязательный,
потому что он действует по умолчанию. Где может встречаться тройка: параметры функций
(включая `self`), переменные цикла (`for inout x in xs` для изменения элементов на месте),
привязки образцов в `switch` и захваты замыканий. Решим, когда дойдём до функций.
