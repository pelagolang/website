## Статус [#status]

Компилятор нулевой стадии, написанный на Rust без зависимостей, поддерживает весь язык. Он проверяет типы и семантику значений, запускает программы в интерпретаторе IR и собирает нативные исполняемые файлы для Linux и Windows. Эти документы — черновики проекта: каждый заканчивается принятыми решениями, а некоторые страницы старше кода, поэтому при расхождении верх берут компилятор и [таблица решений](/docs/project/roadmap).

## С чего начать [#start-here]

- **Впервые видите Pelago?** [Обзор языка](https://github.com/pelagolang/pelago/blob/main/examples/tour.pel) показывает все синтаксические формы, а в [examples/programs](https://github.com/pelagolang/pelago/tree/main/examples/programs) лежат программы, которые запускаются.
- **Хотите собрать?** Клонируйте репозиторий и выполните `cargo build --release`; команды есть в README.
- **Хотите помочь?** Прочитайте [Коммиты и заголовки PR](/docs/project/commits) и [Сценарии PR](/docs/project/pr-scenarios).
