مكتوب بالطريقة التي يكون عليها الدرس الأول في Python، فكرة واحدة في كل مرة. الصياغة
مجرد مسودة نتفاعل معها، وليست قراراً نهائياً.

**ما تقرر حتى الآن:** `fn` للدوال، و`var` و`const`، وأسماء الأنواع بأحرف صغيرة،
وأعداد صحيحة بأحجام من 8 إلى 64 بت، والأنواع العامة `<T>`، ونهاية السطر تنهي العبارة.

## 1. المتغير اسم لقيمة [#1-a-variable-is-a-name-for-a-value]

```
var score = 10
const name = "Dennis"
```

- `var` تنشئ متغيراً يمكنك تغييره لاحقاً.
- `const` تنشئ متغيراً لا يمكنك تغييره. وبسبب دلالات القيم، فإن «لا يمكن تغييره» تعني ذلك فعلاً:
  لا شيء يمكن الوصول إليه عبر هذا الاسم يمكن أن يتغير أيضاً.
- الاسم يأتي أولاً. لا يُكتب أي نوع، لأن المترجم يستنتجه.

## 2. تغيير متغير [#2-changing-a-variable]

```
var score = 10
score = 15          // fine
score += 5          // score is now 20

const pi = 3.14
pi = 3.2            // error: pi is const
```

## 3. الأنواع [#3-types]

لكل قيمة نوع، ويحتفظ المتغير بنوعه إلى الأبد. وهذا هو الفرق الكبير عن Python.

```
var score = 10
score = "ten"       // error: score is an int, "ten" is a string
```

| النوع | يحمل | مثال |
|---|---|---|
| `int` | أعداد صحيحة | `42`, `-7` |
| `float` | أعداد عشرية | `3.14` |
| `bool` | صواب أو خطأ | `true` |
| `char` | حرف واحد | `'a'` |
| `string` | نص | `"hello"` |

أحجام دقيقة عندما تهتم بالذاكرة:

| بإشارة | بلا إشارة | نطاق النوع بإشارة |
|---|---|---|
| `int8` | `uint8` | -128 to 127 |
| `int16` | `uint16` | نحو -32 ألفاً إلى 32 ألفاً |
| `int32` | `uint32` | نحو -2.1 مليار إلى 2.1 مليار |
| `int64` | `uint64` | نحو -9.2 كوينتيليون إلى 9.2 كوينتيليون |

و`float32` و`float64` للأعداد العشرية.

## 4. كتابة النوع بنفسك [#4-writing-the-type-yourself]

يأتي النوع بعد الاسم، كما في TS. لا تحتاج إليه إلا عندما لا يستطيع المترجم
استنتاجه، أو عندما تريد أن تكون صريحاً.

```
var score: int = 10
const ratio: float = 0.5
var small: int8 = 100
var count: int            // error: a variable must be given a value
```

يجب دائماً إعطاء المتغير قيمة عند إنشائه. لا توجد متغيرات غير مهيأة ولا null،
مما يزيل فئة كاملة من الأخطاء.

## 5. الطباعة والتعليقات [#5-printing-and-comments]

```
print("Hello")
print(score)
/// this is a comment
```

## 6. التحويل بين الأنواع (اقتراح، من ابتكارنا) [#6-converting-between-types-proposal-custom]

تُكتب التحويلات دائماً صراحة ولا تحدث بصمت. الاقتراح: كلمة بسيطة هي `to`.

```
const whole = 7
const decimal = whole to float      // 7.0
const text = whole to string        // "7"
```

لا يسمح المترجم بـ `to` إلا عندما لا يمكن أن يضيع شيء. أما التحويلات التي قد تفقد
معلومات أو تفشل فستحتاج إلى صياغة مختلفة وظاهرة. سنحدد ذلك عندما نصل إلى الأخطاء.

## 7. سلاسل نصية تحتوي قيماً (تقرر: علامتنا الخاصة `#`) [#7-strings-with-values-inside-decided-our-own--marker]

العلامة `#` متبوعة باسم تضع تلك القيمة في النص. وإذا كان المطلوب أكبر من اسم،
فضعه بين قوسين.

```
print("Score: #score")              // Score: 10
print("Next: #(score + 1)")         // Next: 11
print("A literal hash: \#")         // A literal hash: #
```

يُفحص التعبير عند ترجمة البرنامج، فيكون الخطأ خطأً قبل تشغيل البرنامج. أما التحكم في التنسيق
(الكسور العشرية، العرض) والسلاسل متعددة الأسطر والسلاسل الخام فتأتي لاحقاً ولا تغيّر هذه العلامة.

## ما هو من ابتكارنا بالفعل [#what-is-already-our-own]

الصياغة هي أرخص مكان للاختلاف، لذا فالقائمة أدناه تتعلق في معظمها بما *تفعله* اللغة.
كل ما هنا اختيار متعمد وليس نسخاً.

- لغة تشبه TS **بلا GC وبلا مراجع تُخزَّن**، بدلالات القيم فقط.
- **تكرار `inout` عند موضع الاستدعاء**، فترى كل تعديل في المكان الذي يحدث فيه.
- **`const` غير قابل للتغيير حقاً**، حتى الأعماق.
- **لا null.** الغياب نوع (`option<T>`) وليس مفاجأة.
- **تحويلات تُكتب بـ `to`**، ولا تُسمح إلا عندما لا يضيع شيء (اقتراح).
- **سلاسل نصية تُدرج القيم بـ `#`**، وهي علامة لم نرها في مكان آخر.
- **`switch`/`case` واحد هو أيضاً مطابقة للأنماط.**
- **كفاءة الرموز (tokens) هدف تصميمي**، تُقاس بمحللات رموز حقيقية.

## قرارات المسودة 2 [#decisions-from-draft-2]

- **[B1]** يقبل المترجم أي نمط تسمية. أما المكتبة القياسية والمنسّق فيختاران نمطاً واحداً.
- **[B2]** `int` دائماً 64 بتاً بالضبط.
- **[B3]** أسماء الأنواع بأحرف صغيرة. (مفتوح: وأنواعك الخاصة أيضاً؟)
- **[B4]** تُكتب التحويلات `x to float`.

- **[B5]** تستخدم السلاسل النصية `#name` و`#(expression)` لإدراج القيم.
- **[B6]** يُسمح للأنواع التي تعرّفها بأسماء بأحرف صغيرة وبأسماء تبدأ بحرف كبير. يقبل المترجم
  أياً منهما، كما في أسماء المتغيرات (B1). ويستخدم المنسّق والمكتبة القياسية حرفاً كبيراً
  للأنواع التي تعرّفها لتبرز. ولا يمكن لنوع وقيمة في النطاق نفسه أن يتشاركا الاسم.

## لا يزال مفتوحاً [#still-open]

**[B7] الكلمة المفتاحية `let`.** محجوزة وغير مستخدمة حالياً. المرشح الأول لاحقاً:
العضو للقراءة فقط في ثلاثي أنماط الوصول (`let` / `inout` / `sink`)، وربما يكون اختيارياً
لأنه الافتراضي الصامت. أماكن ظهور الثلاثي: معاملات الدوال
(بما فيها `self`)، ومتغيرات الحلقات (`for inout x in xs` لتغيير العناصر في مكانها)،
وربط الأنماط في `switch`، والتقاطات الإغلاقات. نقرر عند الوصول إلى الدوال.
