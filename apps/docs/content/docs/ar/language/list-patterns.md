أنماط تنظر داخل قائمة أو مصفوفة أو شريحة (slice). وهي تنسجم مع كل ما في `switch.md`: فروع `switch`، و`is` في الشروط، و`guard ... else`، والحرّاس مع `if`، والبدائل، و`name is pattern`.

## 1. الأشكال [#1-the-shapes]

```
switch xs {
    case []:                       "empty"
    case [x]:                      "one: #x"
    case [a, b]:                   "two: #a and #b"
    case [first, ...rest]:         "#first, then #(rest.len()) more"
}
```

| النمط | يطابق |
|---|---|
| `[]` | قائمة بلا عناصر |
| `[a, b]` | عنصرين بالضبط، مرتبطين بـ `a` و`b` |
| `[a, ...rest]` | عنصرًا واحدًا أو أكثر؛ `rest` هو كل ما بعد `a` (وقد يكون فارغًا) |
| `[...init, last]` | عنصرًا واحدًا أو أكثر؛ `init` هو كل ما قبل `last` |
| `[first, ...mid, last]` | عنصرين أو أكثر، ويرتبط الجزء الأوسط بـ `mid` |
| `[first, ...]` | عنصرًا واحدًا أو أكثر؛ يُتجاهل الباقي (`...` مجردة) |
| `[0, x]`, `[.circle(r), ...]` | يمكن أن تكون العناصر أي نمط: قيمًا حرفية، ونطاقات، وحالات enum، وقوائم متداخلة |

- **علامة الباقي هي `...`**، وهي الرمز نفسه المستخدم للنشر (spread) في `[0, ...xs, 99]`: في التعبير تنشر العناصر إلى الخارج، وفي النمط تجمع العناصر إلى الداخل. وتحتفظ أنماط البنى (struct) بـ `..` لمعنى «تجاهل الحقول الأخرى»؛ والفرق بينهما أن باقي القائمة له طول وعادةً اسم.
- علامة باقٍ واحدة على الأكثر في كل نمط.
- تعمل مع `[T]` و`[T; N]` وعروض الشرائح. ومع المصفوفة ذات الحجم الثابت يكون الطول معروفًا، فيطابق `[a, b]` المصفوفة `[int; 2]` دائمًا، والمصرِّف يعرف ذلك.

## 2. الباقي هو عرض [#2-the-rest-is-a-view]

`rest` هو **عرض شريحة** (slice view) (collections.md، القسم 2) وليس قائمة جديدة. لذا لا تكلّف إنشاءه شيئًا (مؤشر وطول)، وهو كأي عرض يعيش بقدر ما يعيش الفرع ولا يمكن تخزينه أو إرجاعه. للاحتفاظ به: `copy rest`.

```
fn sum(xs: [int]) -> int {
    switch xs {
        case []:             0
        case [h, ...t]:      h + sum(t)          // t is a view; passing it down is fine
    }
}

fn count(xs: [int], acc: int) -> int {
    switch xs {
        case []:             acc
        case [_, ...t]:      become count(t, acc + 1)    // guaranteed tail call
    }
}
```

## 3. أنماط الوصول [#3-access-modes]

تعمل أنماط الوصول على الارتباطات كما في كل مكان. ويوضع النمط أمام الارتباط الذي ينطبق عليه:

```
switch inout xs {
    case [inout first, ...inout rest]:
        first += 1                  // changes xs[0] in place
        rest.reverse!()             // changes the rest in place
    case []: ...
}
```

- الافتراضي للقراءة فقط (`let`). ويتطلب `inout` أن يكون الشيء المفحوص `inout` أيضًا.
- **`sink` غير مسموح على العناصر**: فسحب عنصر واحد من قائمة سيترك فجوة. لتفكيك قائمة كاملة استخدم دوالًا من نمط `pop`/`remove`، أو نمط قائمة `sink` في المستقبل (القسم 7).

## 4. أين تعمل [#4-where-they-work]

```
if args is [cmd, ...rest] { run(cmd, rest) }

guard args is [path] else { return err(usage()) }       // path is usable after the guard

switch line.split(" ").to_list() {
    case ["add", name]:            add!(name)
    case ["remove", name]:         remove!(name)
    case ["list"]:                 list()
    case ["rename", old, new]:     rename!(old, new)
    case [cmd, ...]:               print("unknown command #cmd")
    case []:                       print("empty line")
}
```

- **الاستيفاء (exhaustiveness):** يتتبع المصرِّف الأطوال. `[]` مع `[_, ...]` مجموعة كاملة؛ وكذلك `[]` و`[_]` و`[_, _, ...]`. وتُذكر الأطوال الناقصة في رسالة الخطأ.
- **يجب ألا تفشل التصريحات.** لا يُقبل `const [a, b] = xs` إلا حين يكون `xs` مصفوفة ثابتة الحجم بهذا الطول (`[int; 2]`). وللقائمة استخدم `guard xs is [a, b] else { ... }` أو `if xs is`.
- تعمل البدائل حين تربط الأسماء نفسها: `case [x], [x, _]:`.
- يعمل `name is pattern`: فـ `case whole is [first, ...]:` يحتفظ بالقائمة وبعنصرها الأول.
- **النص يدعم الاثنين**: الحالات الحرفية وأنماط القوائم (LP7). فعلى `string` أو `str` تكون العناصر من النوع `char` ويكون الباقي عرض `str`: `case ['a', ...rest]:` أو `case [c, ...]:`. وتبقى القيم الحرفية الطريقة البسيطة لاختبار قيمة كاملة (`case "add":`). تُعدّ الأطوال بالمحارف، لذا يمرّ اختبار الطول على النص مرة واحدة؛ والمطابقة من البداية لا تفك ترميز أكثر مما يحتاجه النمط.

## 5. إغلاق مسألة المُنشِئات (B5) [#5-closing-the-builder-question-b5]

احتاجت المُنشِئات (builders) إلى طريقة لتخطي العناصر غير المطابقة. و`is` يربط الأسماء أصلًا، فلا حاجة إلى صياغة جديدة. المرشِّح المكتوب بـ `is` يجعل أسماءه متاحة للنتيجة:

```
const radii = [s of shapes if s is .circle(r) ~> r]                  // only circles
const firsts = [x of rows if x is [first, ...] ~> first]             // rows that are not empty
const values = [o of opts if o is some(v) ~> v * 2]                  // some options only
```

(حالة الوجود في `option` هي `some(v)`؛ انظر القرارات أدناه.)

## 6. لماذا لا تصاميم أخرى [#6-why-not-other-designs]

- **`[first, ..rest]` (Rust):** `..` تعني أصلًا «تجاهل الحقول الأخرى» في أنماط البنى، و`...` هي النشر الذي يراه الجميع في القوائم.
- **`first :: rest` (ML / Haskell):** أنماط cons تفترض قوائم مترابطة. أما قوائمنا فمصفوفات، و«الباقي» فيها عرض، وحالتا الوسط والنهاية (`[...init, last]`) رخيصتان كالبداية.
- **`match` منفصلة للقوائم:** كان القرار `switch` واحدة لكل شيء.

## 7. مؤجَّل لوقت لاحق (يُراجَع بعد وجود المدقق) [#7-left-for-later-revisit-after-the-checker-exists]

- **للتذكر في الإصدارات القادمة: `sink` في أنماط القوائم.** أنماط قوائم مستهلِكة (`switch sink xs { case [a, ...rest]: ... }`، حيث يصبح `a` و`rest`
  مملوكين). ممكنة حين يستطيع `sink` على قائمة مالكة أن يعيد الأجزاء بأمان؛ وتحتاج إلى المدقق أولًا.
- **الأنماط على الخرائط والمجموعات.** يبقى البحث `map.get(k)` الذي يعيد `option` وتتم مطابقته بالطريقة المعتادة.
- **الأنماط على المُكرِّرات (iterators)**، التي لا يمكن تخزينها وليس لها طول.

## قرارات المسودة 1 [#decisions-from-draft-1]

- **LP1** `...` هي علامة الباقي (مجردة للتجاهل، و`...name` للربط)، وواحدة على الأكثر في كل نمط.
- **LP2** `rest` عرض شريحة مؤقت؛ و`copy rest` يصنع قائمة مملوكة.
- **LP3** تتقدّم أنماط الوصول الارتباط: `[inout first, ...inout rest]`.
- **LP4** `sink` على عناصر نمط القائمة غير مسموح في الإصدار 1. ويبقى في قائمة ما يُراجَع (القسم 7).
- **LP5** يمكن تفكيك المصفوفات الثابتة في تصريحات عادية؛ أما القوائم فتستخدم `guard ... is` أو `if ... is`.
- **LP6** (أ) `if x is pattern` في مُنشِئ يجلب أسماءه إلى النتيجة (يغلق B5). (ب) تُطابَق حالة الوجود في
  `option` بصيغة `some(v)`، وهي كلمة للأنماط فقط مثل `ok` و`err`؛ وتبقى القيم تُكتب مجردة.
- **LP7** يحصل النص على الاثنين: حالات حرفية وأنماط قوائم على `char` مع باقٍ من نوع `str`.
- **LP8** يجوز أن توضع علامة الباقي في الوسط.
